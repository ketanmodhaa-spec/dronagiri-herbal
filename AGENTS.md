# AGENTS.md — Dronagiri Herbal

Standing principles for anyone changing this codebase — people or AI agents.
Project facts, stack and code rules live in CLAUDE.md.

## Principles

1. **Cut taglines, helper text and secondary labels.** If a screen needs them to make sense, fix the layout.

2. **Elevate UX, DX and AX together — always, without breaking anything.** Make the best decision for the user experience (customers and Sarita), the developer experience (whoever maintains the code next), and the agent experience (AI agents reading and changing it). When they pull apart, find the option that serves all three rather than trading one away. Nothing that works today may break.
